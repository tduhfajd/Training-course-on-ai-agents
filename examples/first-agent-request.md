# Первый запрос после описания идеи

```text
Прочитай idea.md или task.md и только необходимые материалы.
Коротко перескажи цель, нужный результат и ограничения.
Задай вопросы, без которых меняется следующий шаг, по одному.
Предложи небольшой результат и 2–3 проверяемых критерия.
Если есть существенный выбор, сравни варианты. Если все ясно, начни
разрешенную локальную подготовку. Не выполняй внешние действия вне поручения.
Неизвестное обозначай явно. После выполнения покажи результат и проверку.
```

Если пока нужно только обсуждение, добавь: «Сейчас помоги уточнить идею; реализацию начнем после выбора подхода».
