# Запрос для прохождения курса

## Обычный чат — начать проще всего

Открой [самодостаточный запрос](../course/how-to-take-course.md#способ-1-обычный-чат), скопируй весь текст из первой рамки и отправь его в чат. Передавать другие страницы курса не нужно.

В конце скопируй итоговую запись в привычные заметки или документ.

## Помощник уже читает папку курса

```text
Я новичок. Прочитай START_HERE.md и проведи меня по первому проекту.
Материалы курса используй как методику, не изменяй их.
Для моей задачи создай отдельную папку в student-workspace/.
Используй один документ с разделами «Задача», «Результат»,
«Проверка», «Что запомнить». Отдельные файлы пока не нужны.
Задавай вопросы по одному, объясняй простыми словами.
Если не видишь START_HERE.md, скажи об этом.
```

Если папка недоступна, используй способ с обычным чатом выше.
