# Законченные учебные кейсы

Все ситуации и числа ниже **вымышлены для обучения**, не данные семьи, коллег или магазинов автора. Примеры показывают форму результата и проверки; это не записи реального прохождения учениками.

| Кейс | Что тренирует | Что уже есть |
| --- | --- | --- |
| [Семейный выходной](family-weekend.md) | Ограничения, неизвестное, выбор | Задача, материалы, решение, результат, проверка |
| [Рабочая записка](work-report.md) | Строки данных, дубли, расходы | CSV, воспроизводимый расчет, записка с ограничениями |
| [Учебное занятие](learning-session.md) | Работа только по источнику и перенос навыка | Исходный текст, план, упражнение, ответы, проверка |

Названия вроде `task.md` и `verification.md` показывают назначение частей примера. Это могут быть разделы одного документа; создавать такой набор файлов не требуется.

Не копируй готовый ответ до собственной попытки. Можно попросить агента сначала выдать только задание, а после выполнения — сравнить с разбором.
