# Демо-кейс: первая задача за 90 минут

Этот пример показывает, как должен выглядеть завершенный первый проход курса.

## Исходная задача

Ученик хочет подготовить небольшое семейное путешествие на выходные, но пока есть только общая мысль: “хочется куда-то съездить, чтобы отдохнуть и не устать от организации”.

## Что создает агент

```text
student-workspace/
  weekend-trip/
    idea.md
    decisions.md
    learning-summary.md
    materials/
    knowledge-base/
    results/
      weekend-plan.md
    exports/
```

## Черновик `idea.md`

```markdown
# Идея

## Что я хочу сделать

Спланировать спокойную поездку на выходные.

## Для кого это

Для семьи.

## Почему это важно

Хочется отдохнуть, сменить обстановку и не перегрузить себя организацией.

## Что пока непонятно

- куда ехать;
- какой бюджет;
- сколько времени закладывать на дорогу;
- что будет хорошим результатом.
```

## Вопросы агента

- Какой формат отдыха предпочтителен: природа, город, отель, прогулки, культурная программа?
- Сколько людей едет?
- Есть ли ограничения по бюджету?
- Сколько часов дороги комфортно?
- Что важнее: минимум планирования, новые впечатления или экономия?

## Разделение ролей

Человек решает:

- какой отдых действительно подходит семье;
- какой бюджет комфортен;
- какие компромиссы допустимы;
- какой вариант выбрать.

Агент помогает:

- сравнить варианты;
- составить маршрут;
- сделать чек-лист;
- найти риски;
- оформить итоговый план.

## Первый результат

В `results/weekend-plan.md` появляется:

- 2-3 сценария поездки;
- рекомендуемый вариант;
- примерное расписание;
- список вещей;
- открытые вопросы.

## Итог обучения

Ученик понимает базовый цикл:

```text
сырая мысль -> вопросы -> варианты -> выбор -> первый результат -> проверка
```
