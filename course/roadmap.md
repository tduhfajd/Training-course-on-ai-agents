# Дорожная карта развития курса

## Версия 0.1: MVP

Цель: провести первые занятия с 1-2 людьми и проверить, понятен ли подход.

Состав:

- обзор курса;
- методика;
- 7 модулей;
- шаблоны;
- упражнения;
- гайд ведущего.

Критерий успеха:

- ученик смог взять свою задачу и получить первый полезный результат с агентом.

## Версия 0.2: Примеры

Добавить 3 полностью разобранных кейса:

- семейная задача;
- рабочая задача;
- творческая или обучающая задача.

Для каждого кейса:

- исходный `idea.md`;
- диалоговые запросы;
- база знаний, если нужна;
- план;
- итоговый результат;
- разбор ошибок.

## Версия 0.3: Презентация

Сделать короткую презентацию для первого занятия:

- зачем нужен проектный подход;
- почему промптов недостаточно;
- базовый цикл;
- демонстрация на живой задаче;
- домашнее задание.

## Версия 0.35: Техническая практика

Добавить короткие демонстрации:

- как вести проект в Markdown;
- как смотреть структуру в Cursor или VS Code;
- как работать с агентом в Codex;
- как из Markdown получить PDF, DOCX или презентацию;
- как понять, что база знаний уже просится в скил.

## Версия 0.4: Корпоративная адаптация

Добавить материалы для коллег:

- командные правила работы с AI-агентами;
- шаблон проектного репозитория;
- правила безопасности и конфиденциальности;
- чек-лист качества;
- примеры для маркетинга, аналитики, разработки и менеджмента.

## Версия 1.0: Полный курс

Состав:

- программа на 4-6 занятий;
- презентации;
- рабочая тетрадь;
- примеры;
- задания;
- чек-листы;
- библиотека промптов;
- инструкции по инструментам;
- модуль по созданию собственных скилов;
- финальный проект ученика.
