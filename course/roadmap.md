# Дорожная карта развития курса

Для кого: автор курса. Это не часть обязательного пути ученика.

## Версия 1.0: Agent-guided starter kit

Цель: ученик клонирует репозиторий, просит агента провести его по курсу и за 90 минут получает первый полезный результат по своей реальной задаче.

Состав:

- `START_HERE.md`;
- маршрут “Первый проект за 90 минут”;
- 3 трека;
- обзор курса;
- методика;
- 7 модулей;
- шаблоны;
- упражнения;
- гайд ведущего.

Критерий успеха:

- агент создал `student-workspace/`;
- ученик выбрал реальную задачу;
- появился первый результат в `results/`;
- создан `learning-summary.md`;
- ученик может повторить процесс на другой задаче.

## Версия 1.1: Примеры

Добавить 3 полностью разобранных кейса:

- семейная задача;
- рабочая задача;
- творческая или обучающая задача.

Для каждого кейса:

- исходный `idea.md`;
- диалоговые запросы;
- база знаний, если нужна;
- план;
- итоговый результат;
- разбор ошибок.

## Версия 1.2: Презентация

Сделать короткую презентацию для первого занятия:

- зачем нужен проектный подход;
- почему промптов недостаточно;
- базовый цикл;
- демонстрация на живой задаче;
- домашнее задание.

## Версия 1.3: Техническая практика

Добавить короткие демонстрации:

- как вести проект в Markdown;
- как смотреть структуру в Cursor или VS Code;
- как работать с агентом в Codex;
- как из Markdown получить PDF, DOCX или презентацию;
- как понять, что база знаний уже просится в скил.

## Версия 1.4: Корпоративная адаптация

Добавить материалы для коллег:

- командные правила работы с AI-агентами;
- шаблон проектного репозитория;
- правила безопасности и конфиденциальности;
- чек-лист качества;
- примеры для маркетинга, аналитики, разработки и менеджмента.

## Версия 2.0: Полный курс

Состав:

- программа на 4-6 занятий;
- презентации;
- рабочая тетрадь;
- примеры;

- библиотека промптов;
