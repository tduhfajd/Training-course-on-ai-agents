# Файлы, инструменты и конечные форматы

Для первого проекта достаточно [варианта с чатом](how-to-take-course.md). Этот материал нужен, если хочется организовать файловую работу.

## Минимальная организация

Создай одну папку задачи с кратким описанием, исходными материалами, решениями, результатом и проверкой. Агенту нужен доступ именно к этой папке, а не ко всему компьютеру. Работай с копией ценного оригинала, если поручение не требует его изменения.

В курсе учебная область — `student-workspace/`. В обычном проекте можно выбрать другое понятное место. Git сохраняет историю изменений, но не обязателен для новичка и не заменяет резервную копию.

## Что считать главным источником

Markdown удобен для текста задачи и решений. Если работа идет в существующей таблице, главным источником могут быть ее данные и формулы. Если редактируется презентация — рабочий файл слайдов. Экспортируй нужный формат по задаче получателя.

Не обещай автоматическое преобразование любого Markdown в любой формат. Оно требует подходящего инструмента и проверки верстки.

## Проверка конечного файла

Попроси агента открыть или отобразить именно передаваемый файл. Проверь переносы, таблицы, формулы, порядок страниц, ссылки и чувствительные данные. При недоступном просмотре отметь, что оформление пока не проверено.

Для сайта нужны реальный сценарий и фактический просмотр на подходящих размерах экрана. Проверка кода сама по себе не подтверждает внешний вид и публичную доступность.

## Инструменты и доступ

Используй уже доступную возможность. Перед подключением внешнего сервиса выясни, что он читает, где обрабатывает данные и может ли записывать изменения. Скил задает порядок работы, MCP соединяет возможности, разрешение определяет допустимые действия — это разные слои.

В исследовании отделяй поиск, чтение страницы и действие в аккаунте. Изолированный браузер может не видеть пользовательскую авторизацию. Не обходи запреты доступа.

Техническое правило браузерной изоляции для этого курса: Playwright использует bundled Chromium с отдельным профилем. Не запускай пользовательский Google Chrome через Playwright, `channel: "chrome"` или `executablePath` и не закрывай обычные процессы пользователя при очистке. Для нужной существующей сессии используй поддерживаемое подключение к уже открытому браузеру.

## Необязательные команды для автора и агента

Из корня курса, без сторонних зависимостей:

```bash
python3 scripts/analyze_training_data.py
python3 scripts/check_course.py
git diff --check
```

Первая команда воспроизводит учебный расчет, вторая проверяет локальные ссылки, якоря и минимальную связность программы. Они не заменяют живое прохождение курса человеком.

Актуальные продуктовые особенности и первичные ссылки — в [исследовании](../research/2026-10-agent-practices.md).
