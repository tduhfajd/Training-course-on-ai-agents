# Первый проект за 90 минут

Для кого: агент и ученик во время практики.

Это основной маршрут курса. Если ученик не знает, с чего начать, агент ведет его именно по этому сценарию.

## Обещание

За 90 минут ученик берет одну реальную задачу, создает рабочую папку, уточняет цель с агентом, выбирает подход, получает первый полезный результат и фиксирует, чему научился.

## Что должно получиться

В `student-workspace/` должна появиться папка первого проекта:

```text
student-workspace/
  first-project/
    idea.md или task.md
    decisions.md
    learning-summary.md
    materials/
    knowledge-base/
    results/
    exports/
```

Минимальный результат:

- задача описана понятным языком;
- есть разделение ролей человека и агента;
- выбран один подход;
- создан первый полезный артефакт;
- результат проверен;
- ученик понимает, как повторить процесс в другой сфере.

## Роли

### Ученик

Приносит реальную задачу, отвечает на вопросы, принимает решения, оценивает пригодность результата.

### Агент

Ведет по маршруту, создает структуру проекта, задает вопросы, предлагает варианты, помогает сделать первый результат и фиксирует выводы.

### Ведущий

Помогает ученику не застрять, просит агента объяснять проще, возвращает внимание к реальной пользе.

## Сценарий на 90 минут

### 0-10 минут. Старт

Агент:

1. читает `START_HERE.md`;
2. создает `student-workspace/`;
3. объясняет ученику, что курс будет проходиться на реальной задаче;
4. предлагает выбрать один из треков:
   - личная задача;
   - рабочая задача;
   - творческая или учебная задача.

Результат этапа: выбран трек и примерная задача.

### 10-25 минут. Захват задачи

Агент:

1. создает папку проекта внутри `student-workspace/`;
2. копирует подходящий шаблон из `templates/`;
3. помогает заполнить `idea.md` или `task.md`;
4. пересказывает задачу своими словами.

Результат этапа: есть первый черновик задачи.

### 25-40 минут. Уточнение

Агент задает вопросы:

- какой результат нужен;
- для кого это делается;
- почему это важно;
- какие есть ограничения;
- что должен решить человек;
- что можно поручить агенту;
- как понять, что результат достаточно хорош.

Результат этапа: задача стала яснее, появились критерии успеха.

### 40-55 минут. Варианты

Агент предлагает 2-3 подхода:

- быстрый и простой;
- сбалансированный;
- более амбициозный.

Для каждого подхода агент объясняет:

- что получится;
- плюсы;
- минусы;
- риски;
- когда стоит выбрать именно его.

Результат этапа: ученик выбирает один подход и фиксирует решение в `decisions.md`.

### 55-75 минут. Первый результат

Агент помогает создать первый полезный артефакт.

Примеры:

- план поездки;
- структура статьи;
- черновик презентации;
- план обучения;
- список требований;
- прототип документа;
- простой технический прототип.

Результат этапа: в `results/` появляется первый результат.

### 75-85 минут. Проверка

Агент проверяет результат:

- соответствует ли он цели;
- понятен ли он человеку;
- хватает ли конкретики;
- есть ли ошибки или слабые места;
- что нужно улучшить прямо сейчас.

Результат этапа: внесены 1-3 точечных улучшения.

### 85-90 минут. Завершение

Агент создает `learning-summary.md`:

- какая задача была выбрана;
- какой прием работы с агентом освоен;
- что получилось;
- что можно повторить самостоятельно;
- какой следующий шаг.

Результат этапа: у ученика есть итог и ощущение завершенного первого цикла.

## Готово, если

- `student-workspace/` создана и не попадает в Git;
- внутри есть папка проекта;
- задача описана в `idea.md` или `task.md`;
- есть первый результат в `results/`;
- есть `decisions.md`;
- есть `learning-summary.md`;
- ученик может объяснить базовый цикл: задача, контекст, вопросы, варианты, выбор, результат, проверка.
