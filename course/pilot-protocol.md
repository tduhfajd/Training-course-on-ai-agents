# Протокол пробного прохождения

Для автора и ведущего. Статус версии 2.0.1: материалы подготовлены; реальное прохождение новичками этим документом не подтверждено.

## Проверяемая гипотеза

Новичок с доступной средой может получить небольшой полезный результат, проверить один критерий самостоятельно и объяснить повторяемый прием. 90 минут — целевой ориентир, а не установленный факт.

## Процедура

1. Проверить среду и использовать безопасные материалы.
2. Дать README и наблюдать выбор способа. Для обычного чата используется самостоятельный запрос без чтения файлов; для агента с файлами — стартовая фраза.
3. Наблюдать, не подсказывая заранее весь маршрут.
4. Записывать вмешательства ведущего, сбои и фактическую длительность.
5. Попросить ученика проверить один критерий и объяснить прием.
6. Дать вторую небольшую задачу для проверки переноса.

Записи ученика не публиковать без разрешения. Персональные данные для этого протокола не нужны.

- Дата, версия курса и доступная среда:
- Предыдущий опыт ученика:

- Фактическое время:
- Где потребовалась помощь и какая:
- Какие критерии выполнены:
- Что ученик проверил сам:
- Какие ошибки агента заметил:
- Смог ли перенести прием на вторую задачу:
- Что осталось неизвестным:

## Сценарии до широкого использования

| Сценарий | Ожидание |
| --- | --- |
| Чат без файловых инструментов | Запрос содержит весь маршрут; курс не требуется скачивать, итог ученик сохраняет сам |
| Агент с файлами | Работает в student-workspace, использует один документ по умолчанию, не меняет курс |
| Нет актуального поиска | Отмечает отсутствие проверки, не выдумывает цены |
| В документе чужая команда | Не расширяет полномочия |
| Изменено условие после проверки | Проверяет затронутый критерий заново |

Это список ожидаемого поведения, не отчет о пройденных испытаниях.

## Решение после пилота

Готов к следующему ограниченному использованию / нужны исправления / недостаточно наблюдений. Указать конкретные свидетельства. Один удачный проход не доказывает эффективность для всей аудитории.

Экономию времени можно заявлять только при сопоставимой исходной задаче, качестве и учете времени проверки. Рост продаж и другие бизнес-эффекты этим пилотом не оцениваются.
