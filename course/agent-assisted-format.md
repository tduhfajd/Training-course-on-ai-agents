# Учиться вместе с агентом

Каждый этап дает два результата: продвижение по своей задаче и один понятный прием.

Агент помогает выполнить шаг и коротко объясняет его назначение. Ученик формулирует хотя бы один критерий, проверяет хотя бы один вывод и в конце называет другую задачу для этого приема. Это помогает отличить обучение от пассивного получения готового ответа.

## Как вести занятие

Используй [первый маршрут](first-project-90-min.md). Не загружай в контекст все материалы сразу: агент читает нужное к текущему шагу.

Вместо длинной анкеты достаточно критических вопросов. Вместо согласования каждой локальной правки — понятный объем поручения. Внешние действия требуют соответствующих полномочий.

После крупного этапа можно сказать: «Коротко объясни прием, который мы сейчас использовали». Для проверки: «Покажи, чем подтвержден критерий, и дай мне проверить один пункт самому».

В конце сохраняется одна запись с задачей, результатом, проверкой и итогом обучения. Существенное решение можно записать в разделе задачи. Отдельные файлы не обязательны. Если нужен другой чат, готовится [передача контекста](../templates/handoff-template.md).
