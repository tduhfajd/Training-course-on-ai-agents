# Проверка понятности курса: 19 октября 2026 года

Для автора и ведущего. Проверена версия 2.0, исправления вошли в 2.0.1.

## Как проверялось

Ручное прохождение инструкций по двум путям: обычный чат без файлов и поиска; помощник с доступом к папке курса. Проверены вход из README, первый проект, переход к продолжению, 12 модулей, шаблоны и упражнения.

Для каждого шага задавались вопросы: понятно ли, что делать; все ли нужное уже доступно; объяснены ли термины; требуется ли лишняя настройка; совпадает ли действие с соседними инструкциями.

Это редакторская проверка и сопоставление сценариев. Настоящий новичок не участвовал; отдельная агентная сессия в роли ученика не запускалась. Понятность для реальных людей и длительность занятия этим разбором не установлены.

## Найдено и исправлено

| № | Препятствие до исправления | Изменение |
| --- | --- | --- |
| 1 | «Открой в среде с агентом» не объясняло начало; обычный чат должен был читать недоступные ему файлы | Явный выбор способа и самостоятельный запрос с полным маршрутом |
| 2 | Минимумом назывался комплект из пяти файлов, хотя допускался один документ | Один документ с четырьмя разделами стал основным вариантом в маршруте, инструкции агенту, методике и шаблонах |
| 3 | Термины «артефакт», «критерий», Markdown, пути и команды появлялись до объяснения | Основные слова объяснены при входе, сложные заменены обычными, технические сведения вынесены в необязательную часть |
| 4 | На подготовку отводилось 50 минут до первого результата | Выполнение начинается примерно с 20-й минуты; можно переходить дальше раньше |
| 5 | Домашняя практика требовала ошибку агента, а диалог — обязательную правку | Разрешен верный результат без искусственной ошибки; достаточно личной проверки |
| 6 | Табличная практика зависела от CSV и английских названий колонок | Та же таблица вставлена на страницу по-русски; ее можно скопировать в чат, считать на калькуляторе |
| 7 | Тема скила сразу показывала технический файл | Добавлена обычная инструкция как достаточный первый вариант; оформление файла необязательно |
| 8 | Шкала итогового проекта подразумевала наличие источников даже для задачи по личным предпочтениям | Оцениваются нужные исходные сведения, в том числе полученные от человека |

## Повторное прохождение инструкций

### Обычный чат, нет файлов и поиска

README → «Как начать» → первая рамка с запросом → выбор повестки встречи → исходные сведения и признаки готовности → первый текст → личная проверка длительности → одна итоговая запись → копирование в заметки.

При чтении этого пути не требуется скачивание курса, чтение файла по имени, английское имя документа или команда терминала. Запрос содержит порядок действий. Для задачи по данным пользователя актуальный поиск не нужен.

### Агент уже читает папку курса

README → запрос к START_HERE → первый маршрут → отдельная папка учебных работ → один документ task.md → результат и проверка в его разделах → сообщение о месте сохранения.

Инструкция требует сначала прочитать существующий проект, не перезаписывать чужую работу и не менять курс. Отдельные файлы не являются условием завершения. Если доступа нет, предусмотрен переход к самостоятельному запросу обычного чата.

Это проверка согласованности инструкций, а не наблюдение фактического поведения агента.

### Ошибка, отсутствие данных, хороший результат

- Ошибка найдена: исправить и повторить затронутую проверку.
- Ошибок не найдено: сохранить проверку, не придумывать замечание.
- Важное сведение неизвестно: отметить его, не объявлять обязательный критерий выполненным.
- Материалы не нужны: допускается задача по исходным сведениям пользователя.
- Нужен экспорт: проверить именно конечный файл; обычный текст можно проверить в чате.

## Техническая сверка

Повторно проверены локальные ссылки, якоря и присутствие всех 12 модулей в программе. Учебный расчет воспроизведен. Русская таблица упражнения сверена с исходным CSV построчно, включая точный дубль, знак возврата и неизвестную доставку.

Длительности нового маршрута согласованы: 10 + 10 + 35 + 25 + 10 = 90 минут. Это проверка плана времени, а не измерение длительности реального прохождения.

## Что остается проверить

[Пилот с новичком](../pilot-protocol.md): удалось ли начать без помощи, где человек остановился, смог ли проверить пункт самостоятельно и перенести прием на другую задачу. Отдельно нужно наблюдать фактическое поведение разных помощников и доступность их функций.

Редакторские препятствия из таблицы исправлены; вывод «любой новичок пройдет самостоятельно за 90 минут» не делается.
