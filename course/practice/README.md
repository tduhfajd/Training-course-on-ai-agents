# Практика

Начни с [первого проекта за 90 минут](../first-project-90-min.md). Если сложно выбрать задачу, посмотри [личные](../tracks/personal-task.md), [рабочие](../tracks/work-task.md) и [учебные](../tracks/creative-learning-task.md) варианты. Обязательного выбора категории нет.

Для обычного чата используй [самодостаточный запрос](../how-to-take-course.md#способ-1-обычный-чат). Если помощник уже читает папку курса, напиши: «Начни с START_HERE.md и проведи меня по первому проекту».

В обоих способах достаточно одного документа с задачей, результатом, проверкой и итогом обучения. При файловом доступе его сохраняет агент в `student-workspace/`, в обычном чате — сам ученик в привычные заметки. [Способы прохождения](../how-to-take-course.md).

Первый проход завершен по [чек-листу](../../templates/completion-checklist-template.md), когда есть полезный результат и конкретная проверка, а ученик может объяснить освоенный прием.

После него доступны [шесть занятий](../study-plan.md), [разобранные кейсы](../../examples/cases/README.md) и упражнения:

1. [Выбрать задачу](../../exercises/00-choose-any-task.md).
2. [Семейная задача](../../exercises/01-family-task.md) или [рабочая](../../exercises/02-work-task.md).
3. [Границы действий](../../exercises/03-boundaries.md).
4. [Проверка данных](../../exercises/04-data-check.md).
5. [Передача контекста](../../exercises/05-handoff.md).
6. [Повторяемый прием](../../exercises/06-repeatable-process.md).

Необязательно выполнять все упражнения на одной задаче.
