# Практическая часть

Практическая часть проходится вместе с агентом. Ее цель - не прочитать все материалы, а получить первый полезный результат на реальной задаче.

## Главный маршрут

Основной сценарий: [Первый проект за 90 минут](../first-project-90-min.md).

В этом маршруте агент:

1. создает `student-workspace/`;
2. помогает выбрать одну реальную задачу;
3. создает папку проекта;
4. копирует шаблон;
5. помогает уточнить задачу;
6. предлагает варианты;
7. помогает выбрать подход;
8. создает первый результат;
9. проверяет результат;
10. фиксирует итог обучения.

## Если сложно выбрать задачу

Подход универсален, поэтому отдельную категорию выбирать не нужно. Если не знаешь, какую задачу взять для первого прохода, посмотри примеры:

- [личные задачи](../tracks/personal-task.md);
- [рабочие задачи](../tracks/work-task.md);
- [творческие и учебные задачи](../tracks/creative-learning-task.md).

После выбора задачи возвращайся к одному основному маршруту: [Первый проект за 90 минут](../first-project-90-min.md).

## Единая стартовая фраза для Codex

```text
Начни с START_HERE.md и проведи меня по первому проекту за 90 минут.
```

## Что должно появиться после практики

```text
student-workspace/
  my-first-project/
    idea.md или task.md
    decisions.md
    learning-summary.md
    materials/
    knowledge-base/
    results/
    exports/
```
