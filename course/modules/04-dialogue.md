# Модуль 4. Диалог с агентом и принятие решений

## Цель

Научиться вести с агентом рабочий диалог, а не просто получать ответы.

## Главная мысль

Лучший результат рождается в итерациях: вопрос, гипотеза, критика, уточнение, выбор.

## Полезные роли агента

- Аналитик: структурирует проблему.
- Исследователь: ищет источники и факты.
- Архитектор: предлагает систему решения.
- Редактор: улучшает текст.
- Критик: ищет слабые места.
- Исполнитель: делает конкретную работу.
- Проверяющий: тестирует результат.

## Запросы, которые стоит освоить

```text
Предложи 3 разных подхода к решению. Для каждого укажи плюсы, минусы, риски и когда его стоит выбрать.
```

```text
Покритикуй этот план как опытный специалист. Найди слабые места, скрытые предположения и вопросы, которые я не задал.
```

```text
Сначала не реализуй. Помоги мне выбрать лучший вариант решения и объясни, по каким критериям выбирать.
```

```text
Теперь реализуй выбранный вариант маленькими шагами. После каждого шага проверяй результат.
```

## Практика

Ученик берет свою задачу и просит агента предложить 3 варианта решения. Затем выбирает один и объясняет почему.

## Результат модуля

Есть выбранный подход, список причин выбора и первый план реализации.
