# Модуль 5. Выбрать инструмент под задачу

Цель — понимать, какое действие нужно, и подключать только необходимое. Для первого проекта достаточно доступного чата, материалов и места сохранения.

## Что чем является

| Сущность | Назначение | Пример |
| --- | --- | --- |
| База знаний | Сведения и источники | Факты о теме занятия |
| Инструкция проекта | Постоянные правила конкретной работы | Не менять исходный отчет |
| Скил | Повторяемый способ работы | Подготовить занятие и самопроверку |
| Инструмент | Выполнить операцию | Прочитать файл, открыть страницу |
| MCP | Соединить AI-приложение с возможностями сервера | Доступ к хранилищу через совместимый сервер |
| Плагин | Упаковать расширения конкретной среды | Скилы и подключения в одном пакете |

Поддержка зависит от продукта. MCP сам по себе не гарантирует безопасность сервера; скил не дает новых прав. [Первичные источники и ограничения](../../research/2026-10-agent-practices.md).

## Выбор в три шага

1. Назови действие: прочитать таблицу, найти условие, подготовить PDF.
2. Проверь, есть ли уже соответствующая возможность и доступ.
3. Используй ее на безопасном примере, затем проверь результат.

Не устанавливай расширение только потому, что оно упомянуто в курсе. Разрешение читать документы не включает право изменять или публиковать их.

## Файлы и экспорт

Задачу и решения можно хранить в обычном текстовом документе. Markdown — простой способ обозначать в таком тексте заголовки и списки. Рабочий файл в привычном редакторе может оставаться главным: формулы в XLSX, слайды в PPTX, редактируемый документ в DOCX. Не превращай формулы в обычный текст ради единого формата.

Создание экспорта и просмотр экспорта — разные шаги. Попроси открыть результат и проверить его реальный вид.

## Браузер

Поисковый инструмент, изолированный браузер агента и обычный браузер человека могут иметь разные сессии и авторизацию. Не считай доступ к одному доступом ко всем. Не обходи блокировки и CAPTCHA; при необходимости передай этот шаг человеку.

Настройка автоматического управления браузером относится к [техническому продолжению](../technical-workflow.md); для первого проекта она не требуется.

## Практика и проверка

Ученик называет одно нужное действие, агент показывает доступный инструмент или честный ручной вариант. Готово: создан проверяемый результат без лишнего подключения. Подробности организации — в [техническом процессе](../technical-workflow.md).
