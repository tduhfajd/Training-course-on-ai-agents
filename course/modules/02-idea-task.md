# Модуль 2. Как описывать идею или задачу

## Цель

Научиться превращать неясную мысль в контекст, с которым агент может работать.

## Главная мысль

Не нужно сразу формулировать идеально. Нужно честно описать то, что уже есть в голове.

## Разница между `idea.md` и `task.md`

`idea.md` подходит, когда:

- есть желание или направление;
- результат еще неясен;
- нужно подумать вместе с агентом;
- есть сомнения и гипотезы.

`task.md` подходит, когда:

- результат понятен;
- есть ограничения;
- нужно выполнить работу;
- можно проверить готовность.

## Что должно быть в хорошем описании

- Контекст.
- Цель.
- Для кого это делается.
- Почему это важно.
- Что уже есть.
- Что непонятно.
- Ограничения.
- Ожидаемый результат.
- Критерии успеха.

## Практика

Ученик заполняет один из шаблонов:

- [idea-template.md](../../templates/idea-template.md)
- [task-template.md](../../templates/task-template.md)

Затем просит агента:

```text
Внимательно изучи idea.md. Сначала кратко перескажи, как ты понял идею. Затем задай мне 5-7 уточняющих вопросов, которые помогут превратить ее в понятный план действий.
```
