# Модуль 3. Исследование и база знаний

## Цель

Научиться поручать агенту исследование и превращать найденную информацию в локальную базу знаний.

## Главная мысль

Если задача требует знаний, сначала нужно построить общий справочник, а уже потом принимать решения.

## Когда нужно исследование

- Тема новая для ученика.
- Информация быстро меняется.
- Нужны источники.
- Есть риск принять решение на основе слухов.
- Нужно сравнить варианты.
- Нужна экспертная рамка.

## Хороший запрос на исследование

```text
Мне нужна база знаний для проекта. Изучи тему, найди надежные источники, отдели факты от рекомендаций, укажи спорные места и создай структурированный Markdown-файл в knowledge-base/.

Важно:
- без воды;
- с ссылками на источники;
- с краткими выводами;
- с разделом "что это значит для моей задачи";
- с вопросами, которые еще нужно прояснить.
```

## Структура базы знаний

```text
knowledge-base/
  topic-overview.md
  sources.md
  open-questions.md
```

## Практика

Ученик выбирает одну область, где ему не хватает знаний, и просит агента создать базу знаний.

## Результат модуля

В проекте появляется первая база знаний, которую можно использовать в дальнейшей работе.

## Связь со скилами

Если похожие исследования или задачи будут повторяться, база знаний может стать основой будущего скила.

Но сначала лучше использовать ее в 1-2 реальных задачах и только потом решать, какие части действительно стоит превращать в устойчивую инструкцию для агента.
