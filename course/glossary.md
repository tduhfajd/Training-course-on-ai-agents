# Словарь простыми словами

Определения служат работе в курсе. Реализация и названия в разных продуктах отличаются; [источники](../research/2026-10-agent-practices.md) позволяют проверить детали.

| Термин | Что означает | Бытовой пример |
| --- | --- | --- |
| Проект | Одна задача с сохраненными материалами и результатом | Подготовка встречи |
| Критерий | Проверяемый признак готовности | Встреча укладывается в 30 минут |
| Markdown / .md | Обычный текст с простой разметкой заголовков и списков | Заметка о задаче |
| CSV | Текстовый файл с данными таблицы | Учебные расходы |
| Бриф | Краткое описание задачи и требований | Для кого готовим письмо |
| Экспорт | Сохранение в другом формате | Получить PDF из документа |
| Свидетельство проверки | Конкретное подтверждение выполненного условия | Пересчитанная сумма |
| Модель | Компонент, который обрабатывает запрос и генерирует ответ или предлагает действие | Предложить структуру письма |
| Чат | Интерфейс общения; может иметь дополнительные инструменты | Обсудить план встречи |
| Агент | Система, которая использует модель и инструменты для последовательных шагов к цели | Прочитать файлы, сделать таблицу, проверить ее |
| Workflow / процесс | Последовательность шагов, часть которых может быть заранее задана | Прочитать отчет → посчитать → подготовить сводку |
| Harness / среда исполнения | Организует инструменты, разрешения, контекст и ход работы агента | Рабочее место помощника |
| Контекст | Информация, доступная при текущей работе модели | Задача, материалы, выбранное решение |
| Память | Механизм сохранения и извлечения информации между сессиями | Предпочтение коротких документов; может устареть |
| AGENTS.md | Принятое рядом агентных инструментов имя файла проектных инструкций | Правила для работы в папке; поддержка зависит от среды |
| Скил / skill | Пакет повторяемых инструкций и необязательных ресурсов | Как готовить учебное занятие по источнику |
| Инструмент / tool | Конкретная операция, которую может вызвать агент | Прочитать таблицу или выполнить поиск |
| MCP | Протокол подключения возможностей серверов к AI-приложениям | Доступ к документам через совместимый сервер |
| Коннектор / app | Интеграция с приложением или сервисом; название зависит от продукта | Подключение хранилища документов |
| Плагин | Пакет возможностей среды; может объединять скилы, инструменты и другие настройки | Установленное расширение для работы с документами |
| Артефакт | Сохраненный результат работы | Документ, таблица, страница |
| Критерий приемки | Условие, по которому можно проверить результат | Бюджет включает доставку или явно обозначает ее неизвестной |
| Evals | Повторяемая оценка поведения на наборе случаев; также название отдельных сервисов | Проверить, что агент не выдумывает данные при пропуске цены |
| Prompt injection | Попытка передать агенту чужую команду внутри читаемых данных | Страница требует выслать архив, хотя пользователь просил сводку |
| Handoff | Короткая передача состояния работы | Что сделано, что проверено, что дальше |
| Идемпотентность | Защита от повторного эффекта одной операции | Повторный запуск не создает второе письмо |
| Повторное чтение | Проверка состояния после действия | Открыть именно сохраненный документ |
| Галлюцинация | Правдоподобное, но неподтвержденное или неверное содержание | Выдуманная ссылка или стоимость |

Читать словарь целиком перед первым проектом не нужно. Возвращайся к слову, когда оно встретится в задаче.
