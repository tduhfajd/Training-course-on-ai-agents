# Короткий вход в теорию

Перед первым проектом достаточно 5–10 минут. Читать все модули не нужно.

1. [Обзор](../overview.md): какой результат получим.
2. [Универсальный подход](../universal-approach.md): что делает человек, а что агент.
3. [Первый маршрут](../first-project-90-min.md): как пройдет работа.

Если хочется разобраться глубже — [методика](../method.md). Термины можно искать по мере встречи в [словаре](../glossary.md).

Главное перед практикой: есть задача, материалы, ограничения и способ проверки. Важный факт нужно сверить, неизвестное назвать, результат сохранить. Техническую настройку можно заменить ручным действием.

Дальше — [практика](../practice/README.md).
