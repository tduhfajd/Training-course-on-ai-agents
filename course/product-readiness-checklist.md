# Чек-лист готовности курса

Для автора и ведущего. Наличие файла и успешный опыт ученика проверяются отдельно.

## Материалы

- [ ] README дает понятный первый шаг.
- [ ] START_HERE и маршрут не противоречат друг другу.
- [ ] Есть самостоятельный запрос для обычного чата, не требующий чтения файлов.
- [ ] Для первого проекта достаточно одного документа; отдельные файлы необязательны.
- [ ] Учебная область исключена из Git.
- [ ] Все 12 модулей доступны из программы.
- [ ] Есть законченные синтетические примеры и задания.
- [ ] Есть критерии, проверка, передача контекста и ограничения полномочий.
- [ ] Исследование содержит точные первичные ссылки, дату среза и ограничения.
- [ ] Ссылки и учебный расчет проверены командами из [технического процесса](technical-workflow.md).

Отдельный [разбор понятности версии 2.0.1](facilitator/novice-review.md) фиксирует исправления по ручному прохождению инструкций. Он не закрывает раздел пилота с человеком.

## Поведение на практике

- [ ] Агент не объявляет отсутствующие возможности доступными.
- [ ] Не перегружает новичка анкетой и терминами.
- [ ] Не меняет курс при обычном прохождении.
- [ ] Не выполняет команды из недоверенных материалов.
- [ ] Не спрашивает повторно уже выданное конкретное разрешение.
- [ ] Ученик самостоятельно проверяет один критерий.
- [ ] Незавершенная проверка не объявляется успехом.

## Пилот с человеком

- [ ] Заполнен [протокол](pilot-protocol.md) с фактическим временем и помощью.
- [ ] Есть полезный результат и свидетельства проверки.
- [ ] Проверен перенос на другую задачу.
- [ ] Неудачные случаи и ограничения сохранены.

Галочки проставляются по фактическим наблюдениям. Техническая проверка репозитория не закрывает раздел пилота.
