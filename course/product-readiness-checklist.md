# Чек-лист готовности продукта

Используй этот список перед тем, как давать курс ученику.

## Репозиторий

- [ ] `README.md` объясняет, что делать за первые 2 минуты.
- [ ] `START_HERE.md` понятен агенту.
- [ ] `student-workspace/` добавлен в `.gitignore`.
- [ ] Есть маршрут [Первый проект за 90 минут](first-project-90-min.md).
- [ ] Есть стартовый промпт в `examples/course-with-agent-prompt.md`.

## Учебный путь

- [ ] Ученик может выбрать один из трех треков.
- [ ] Агент создает папку проекта внутри `student-workspace/`.
- [ ] Агент копирует подходящий шаблон.
- [ ] Агент помогает получить первый результат.
- [ ] Агент создает `learning-summary.md`.
- [ ] Есть критерии завершения первого прохода.

## Материалы

- [ ] Есть шаблоны `idea.md` и `task.md`.
- [ ] Есть шаблон `decisions.md`.
- [ ] Есть шаблон `learning-summary.md`.
- [ ] Есть чек-лист завершения.
- [ ] Есть демо-кейс.

## Опыт ученика

- [ ] Ученик понимает, что курс проходит не в теории, а на реальной задаче.
- [ ] Ученик понимает, что человек принимает решения, агент усиливает процесс.
- [ ] Ученик получает результат за один первый проход.
- [ ] Ученик может объяснить базовый цикл своими словами.

## Перед первым тестом

Попроси ученика открыть репозиторий в Codex и написать:

```text
Начни с START_HERE.md и проведи меня по первому проекту за 90 минут.
```

Не объясняй заранее слишком много. Цель теста - проверить, насколько продукт сам ведет человека.
