# Как проходить курс

## Короткий ответ

Курс лучше клонировать как отдельный репозиторий и проходить его прямо с агентом.

Рабочие файлы ученика при этом должны лежать не среди материалов курса, а в локальной папке `student-workspace/`, которая добавлена в `.gitignore`.

Так репозиторий курса остается чистым, а ученик получает удобное место для своих учебных проектов.

## Рекомендуемая схема

```text
training-course-on-ai-agents/
  README.md
  .gitignore
  course/
  templates/
  exercises/
  examples/
  student-workspace/       # ignored by Git
    vacation-planning/
      idea.md
      materials/
      knowledge-base/
      results/
      exports/

    article-about-topic/
      idea.md
      materials/
      knowledge-base/
      results/
      exports/
```

## Почему не работать прямо в директории курса

Директория курса должна оставаться чистой:

- ее проще обновлять;
- материалы не смешиваются с задачами учеников;
- примеры не путаются с реальными проектами;
- можно проводить курс много раз;
- можно держать курс в Git как методичку.

Рабочие задачи лучше создавать в `student-workspace/`, потому что у каждой задачи будут свои материалы, источники, черновики, решения и финальные результаты.

`student-workspace/` не попадает в Git, поэтому ученик может свободно экспериментировать, не засоряя репозиторий курса.

## Как ученик проходит курс

Лучший формат:

1. Ученик клонирует репозиторий курса.
2. Ученик открывает репозиторий в Codex.
3. Ученик просит агента начать с `START_HERE.md`.
4. Агент создает `student-workspace/`.
5. Агент ведет ученика по маршруту [Первый проект за 90 минут](first-project-90-min.md).
6. Агент помогает выбрать трек:
   - личная задача;
   - рабочая задача;
   - творческая или учебная задача.
7. Агент создает внутри `student-workspace/` папку под первую реальную задачу.
8. Агент копирует туда нужный шаблон: `idea.md`, `task.md`, чек-лист или бриф.
9. Ученик заполняет шаблон.
10. Агент читает курс как методику, а работает с файлами в `student-workspace/`.

## Стартовый запрос агенту

```text
Я хочу пройти курс по работе с AI-агентами.

Материалы курса лежат здесь:
/path/to/training-course-on-ai-agents

Создай для моего обучения локальную папку:
/path/to/training-course-on-ai-agents/student-workspace

Внутри нее создай отдельную папку для моей первой задачи.

Твоя задача:
- используй курс как методику;
- проводи меня пошагово;
- рабочие файлы создавай и изменяй только в student-workspace/;
- не изменяй материалы курса без отдельной просьбы;
- после каждого шага кратко объясняй, какой прием работы с агентом я сейчас освоил.

Начни с чтения README курса, затем предложи мне выбрать первую реальную задачу и создай для нее рабочую папку.
```

## Как выглядит завершенный первый проход

```text
student-workspace/
  my-first-project/
    idea.md или task.md
    decisions.md
    learning-summary.md
    materials/
    knowledge-base/
    results/
      first-result.md
    exports/
```

Первый проход завершен, если ученик получил первый полезный результат и может объяснить процесс:

```text
задача -> контекст -> вопросы -> варианты -> выбор -> результат -> проверка
```

## Роль курса

Курс отвечает на вопросы:

- как думать;
- какие шаги проходить;
- какие шаблоны использовать;
- как проверять результат;
- когда подключать инструменты;
- когда задумываться о скилах.

## Роль `student-workspace/`

`student-workspace/` отвечает за конкретные учебные задачи:

- исходная идея;
- материалы;
- база знаний;
- решения;
- результаты;
- экспортные документы;
- возможные черновики будущих скилов.

## Когда можно работать прямо в директории курса

Это допустимо только для разработки самого курса:

- улучшить модуль;
- добавить шаблон;
- написать пример;
- подготовить презентацию курса;
- обновить методику.

Для прохождения курса учеником лучше использовать отдельную директорию.

В этом репозитории такой директорией по умолчанию является `student-workspace/`.
