# Примеры задач: творчество и обучение

Это не отдельный маршрут курса, а подсказка для выбора первой задачи. После выбора задачи используется общий маршрут [Первый проект за 90 минут](../first-project-90-min.md).

## Для каких задач

- написать статью;
- подготовить выступление;
- придумать программу обучения;
- изучить новую тему;
- развить хобби;
- подготовить контент;
- сделать творческий проект.

## Зачем смотреть эти примеры

Показать, что агент может усиливать мышление и творчество: помогать со структурой, вариантами, обратной связью, источниками и первым черновиком.

## Что должен принести человек

- интерес;
- исходную идею;
- позицию;
- аудиторию;
- желаемое впечатление;
- личные ограничения;
- финальное авторское решение.

## Что может сделать агент

- предложить структуру;
- расширить идею;
- найти слабые места;
- подобрать источники;
- сделать черновик;
- предложить упражнения;
- выступить критиком;
- помочь улучшить результат.

## Первый полезный результат

Один из вариантов:

- структура статьи;
- план выступления;
- программа занятия;
- план обучения;
- список источников;
- творческий brief;
- черновик первого фрагмента.
