# Примеры задач: работа

Это не отдельный маршрут курса, а подсказка для выбора первой задачи. После выбора задачи используется общий маршрут [Первый проект за 90 минут](../first-project-90-min.md).

## Для каких задач

- подготовить встречу;
- собрать требования;
- написать документ;
- сделать презентацию;
- подготовить отчет;
- провести исследование;
- сравнить решения;
- спланировать проект.

## Зачем смотреть эти примеры

Показать, как агент помогает быстрее двигаться в рабочей задаче без потери контроля над смыслом, качеством и ответственностью.

## Что должен принести человек

- цель;
- аудиторию;
- ограничения;
- контекст команды;
- критерии качества;
- допустимые компромиссы;
- финальное решение.

## Что может сделать агент

- структурировать задачу;
- найти пробелы;
- предложить подходы;
- подготовить черновик;
- улучшить формулировки;
- проверить логику;
- сделать список рисков;
- подготовить следующий шаг.

## Первый полезный результат

Один из вариантов:

- повестка встречи;
- структура документа;
- черновик письма;
- план проекта;
- таблица сравнения;
- outline презентации;
- список требований.
