# Трек: рабочая задача

## Для каких задач

- подготовить встречу;
- собрать требования;
- написать документ;
- сделать презентацию;
- подготовить отчет;
- провести исследование;
- сравнить решения;
- спланировать проект.

## Цель трека

Показать, как агент помогает быстрее двигаться в рабочей задаче без потери контроля над смыслом, качеством и ответственностью.

## Что должен принести человек

- цель;
- аудиторию;
- ограничения;
- контекст команды;
- критерии качества;
- допустимые компромиссы;
- финальное решение.

## Что может сделать агент

- структурировать задачу;
- найти пробелы;
- предложить подходы;
- подготовить черновик;
- улучшить формулировки;
- проверить логику;
- сделать список рисков;
- подготовить следующий шаг.

## Первый полезный результат

Один из вариантов:

- повестка встречи;
- структура документа;
- черновик письма;
- план проекта;
- таблица сравнения;
- outline презентации;
- список требований.

## Стартовая фраза

```text
Я хочу решить рабочую задачу с помощью агента. Помоги мне уточнить цель, аудиторию, критерии качества и ограничения, а затем предложи несколько практичных подходов.
```
