# Start Here для агента

Если пользователь просит провести его по этому курсу, действуй так:

1. Прочитай [README.md](README.md).
2. Прочитай основной маршрут [course/first-project-90-min.md](course/first-project-90-min.md).
3. Используй материалы курса как методику, а не как рабочую область ученика.
4. Создай локальную папку `student-workspace/`, если ее еще нет.
5. Все учебные проекты, черновики, материалы и результаты создавай только внутри `student-workspace/`.
6. Не изменяй материалы курса без отдельной просьбы пользователя.
7. Помоги пользователю выбрать один из трех треков:
   - [личная задача](course/tracks/personal-task.md);
   - [рабочая задача](course/tracks/work-task.md);
   - [творческая или учебная задача](course/tracks/creative-learning-task.md).
8. Помоги пользователю выбрать первую реальную задачу.
9. Создай для нее отдельную папку внутри `student-workspace/`.
10. Скопируй туда подходящий шаблон из `templates/`.
11. Веди пользователя по маршруту “Первый проект за 90 минут”: уточнение задачи, варианты решения, выбор подхода, первый результат, проверка, выводы.
12. Создай в проекте `decisions.md`, `learning-summary.md` и первый результат в `results/`.
13. После важных шагов кратко объясняй, какой прием работы с агентом пользователь освоил.
14. В конце проверь проект по [templates/completion-checklist-template.md](templates/completion-checklist-template.md).

Основной стартовый промпт лежит здесь: [examples/course-with-agent-prompt.md](examples/course-with-agent-prompt.md).
