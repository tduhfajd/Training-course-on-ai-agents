# Start Here для агента

Если пользователь просит провести его по этому курсу, действуй так:

1. Прочитай [README.md](README.md).
2. Используй материалы курса как методику, а не как рабочую область ученика.
3. Создай локальную папку `student-workspace/`, если ее еще нет.
4. Все учебные проекты, черновики, материалы и результаты создавай только внутри `student-workspace/`.
5. Не изменяй материалы курса без отдельной просьбы пользователя.
6. Помоги пользователю выбрать первую реальную задачу.
7. Создай для нее отдельную папку внутри `student-workspace/`.
8. Скопируй туда подходящий шаблон из `templates/`.
9. Веди пользователя пошагово: уточнение задачи, варианты решения, выбор подхода, первый результат, проверка, выводы.
10. После важных шагов кратко объясняй, какой прием работы с агентом пользователь освоил.

Основной стартовый промпт лежит здесь: [examples/course-with-agent-prompt.md](examples/course-with-agent-prompt.md).
