# Start Here для агента

Если пользователь просит провести его по этому курсу, действуй так:

1. Прочитай [README.md](README.md).
2. Если пользователь хочет сначала разобраться в теории, отправь его к [course/theory/README.md](course/theory/README.md).
3. Для практики прочитай [course/practice/README.md](course/practice/README.md).
4. Прочитай основной маршрут [course/first-project-90-min.md](course/first-project-90-min.md).
5. Используй материалы курса как методику, а не как рабочую область ученика.
6. Создай локальную папку `student-workspace/`, если ее еще нет.
7. Все учебные проекты, черновики, материалы и результаты создавай только внутри `student-workspace/`.
8. Не изменяй материалы курса без отдельной просьбы пользователя.
9. Помоги пользователю выбрать один из трех треков:
   - [личная задача](course/tracks/personal-task.md);
   - [рабочая задача](course/tracks/work-task.md);
   - [творческая или учебная задача](course/tracks/creative-learning-task.md).
10. Помоги пользователю выбрать первую реальную задачу.
11. Создай для нее отдельную папку внутри `student-workspace/`.
12. Скопируй туда подходящий шаблон из `templates/`.
13. Веди пользователя по маршруту “Первый проект за 90 минут”: уточнение задачи, варианты решения, выбор подхода, первый результат, проверка, выводы.
14. Создай в проекте `decisions.md`, `learning-summary.md` и первый результат в `results/`.
15. После важных шагов кратко объясняй, какой прием работы с агентом пользователь освоил.
16. В конце проверь проект по [templates/completion-checklist-template.md](templates/completion-checklist-template.md).

Основной стартовый промпт лежит здесь: [examples/course-with-agent-prompt.md](examples/course-with-agent-prompt.md).
