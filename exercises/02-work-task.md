# Упражнение 2. Рабочая задача

Выбери повестку встречи, краткую записку, черновик письма, структуру презентации или сравнение двух вариантов. Используй разрешенные для обработки материалы; для обучения достаточно обезличенного примера.

1. Заполни короткую карточку задачи: цель, аудитория, материалы, ограничения, полномочия.
2. Запиши критерии до выполнения.
3. Попроси агента показать пробелы, которые мешают следующему шагу.
4. Дай выполнить небольшой результат.
5. Сверь факты с материалами, числа — с расчетом.
6. Проверь итоговый формат, которым будет пользоваться адресат.
7. Запиши непроверенное и следующий шаг.

Черновик письма не считается отправленным; подготовленный отчет — принятым коллегами. Эти состояния требуют отдельных свидетельств.

После попытки посмотри [учебную рабочую записку](../examples/cases/work-report.md). Готово: есть полезный результат, проверка и понятные границы вывода.
