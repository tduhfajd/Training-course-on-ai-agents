# Курс: как решать любые задачи с AI-агентами

Практический мини-курс о том, как использовать Codex, Cursor и похожих AI-агентов не как чат для разовых вопросов, а как партнера по работе над любыми задачами: от сырой идеи до готового результата.

Главный фокус курса - универсальность подхода. Один и тот же принцип работает для разработки приложения, написания статьи, подготовки презентации, планирования поездки, изучения новой темы, хобби, рабочих документов и семейных задач.

Курс лучше проходить сразу вместе с агентом. То есть ученик не просто читает материалы, а открывает свою реальную задачу, запускает агента и проходит модули в живом рабочем диалоге. Так сам способ обучения совпадает с тем навыком, который курс развивает.

Курс вырос из личного рабочего подхода:

- заводить под задачу отдельную папку или репозиторий;
- фиксировать исходную мысль в `idea.md` или `task.md`;
- вести основную документацию в легких Markdown-файлах;
- складывать рядом все материалы, файлы и источники;
- при необходимости собирать локальную базу знаний;
- обсуждать решение с агентом итеративно;
- использовать навыки, MCP, плагины и инструменты;
- проверять результат и оставлять понятные артефакты.

## Для кого

- Для членов семьи, которые хотят спокойнее и эффективнее решать бытовые, учебные, творческие и рабочие задачи с ИИ.
- Для коллег, которым нужно быстро перейти от хаотичных запросов к воспроизводимому процессу.
- Для людей без технического бэкграунда, если им показать процесс через понятные жизненные задачи.

## Главная идея

AI-агенту нужен не идеальный промпт, а хороший рабочий контекст.

Контекст создается не одной длинной командой, а проектной средой: файлами, источниками, описанием цели, ограничениями, решениями, проверками и диалогом.

Вторая важная идея: учиться этому лучше не отдельно от практики, а прямо в процессе решения своей задачи. Агент одновременно помогает выполнить задачу и объясняет, как с ним работать.

Третья важная идея: человек и агент делают разную работу.

Человек отвечает за смысл, идеи, вкус, эмпатию, творчество, выбор и понимание жизненного контекста. Агент помогает структурировать, ускорять, валидировать, искать слабые места, выполнять технические шаги, предлагать варианты, обосновывать решения и критиковать результат.

## Быстрый старт для ученика

1. Склонировать репозиторий курса.
2. Открыть его в Codex.
3. Попросить агента провести по курсу.
4. Агент создает локальную папку `student-workspace/`, которая исключена из Git.
5. Внутри `student-workspace/` агент создает отдельную папку под реальную задачу ученика.
6. Неважно, из какой она сферы: работа, дом, творчество, обучение, хобби или технический проект.
7. Агент копирует туда нужный шаблон: [idea-template.md](templates/idea-template.md) или [task-template.md](templates/task-template.md).
8. Ученик заполняет его обычным языком, без попытки звучать “правильно”.
9. Агент читает курс как методику, а все рабочие файлы ведет в `student-workspace/`.
10. Ученик вместе с агентом выбирает план, делает первый результат, проверяет его и фиксирует выводы.

Стартовый запрос можно взять здесь: [course-with-agent-prompt.md](examples/course-with-agent-prompt.md).

## Техническая философия

Базовый формат курса - Markdown. Такие файлы легко читать, хранить в Git, просматривать в репозитории и редактировать агентом.

Если нужен красивый внешний артефакт, агент может позже собрать из Markdown документ в другом формате: PDF, DOCX, презентацию или страницу. Но источник смысла лучше держать в простых текстовых файлах.

Для работы удобно использовать Codex как агентную среду, а Cursor или VS Code как IDE для просмотра структуры проекта, чтения файлов и ручного редактирования.
