# Как решать задачи с AI-агентами

Практический курс для семьи и коллег: от понятной задачи до результата, который можно проверить. **Версия 2.0.1 · 19 октября 2026 года.**

Первый проект занимает ориентировочно 90 минут. Техническая подготовка для него не нужна.

## Быстрый старт для ученика

Если пользуешься обычным чатом с ИИ, открой [готовый запрос для первого занятия](course/how-to-take-course.md#способ-1-обычный-чат). Скопируй его в чат и ответь на первый вопрос помощника. Скачивать курс и создавать папки не нужно.

Если помощник **уже умеет читать папку курса**, напиши ему:

```text
Прочитай START_HERE.md и проведи меня по первому проекту.
Я новичок. Используй один документ для задачи, результата и проверки.
```

Не знаешь, есть ли у помощника доступ к файлам? Выбери обычный чат — этого достаточно для начала.

В первом проекте мы подготовим небольшой план, текст или таблицу, проверим его и сохраним **одну итоговую запись** в привычные заметки или документ. Например, составим повестку встречи на 30 минут и сами сложим время ее блоков.

**Агент** — ИИ-помощник, который может выполнять шаги с помощью доступных ему инструментов. **Проект** в этом курсе — одна задача с сохраненным результатом. **Критерий** — признак, по которому можно проверить готовность.

## Что будем делать

Выбери то, что действительно пригодится: план встречи, письмо, семейный маршрут, учебный материал, исследование или анализ таблицы.

```text
цель → материалы → критерии и границы → небольшой шаг → проверка → решение → сохранение
```

Человек задает смысл и принимает результат. Агент читает материалы, ищет, сравнивает, считает с помощью инструментов, создает и помогает проверять. Доступные действия зависят от среды и разрешений.

После первого проекта у тебя будут задача, полезный результат, запись проверки и короткий итог обучения. Ты сам проверишь хотя бы один критерий и объяснишь, как повторить процесс.

## Принцип курса

Агенту нужен хороший рабочий контекст. А человеку — возможность понять результат и проверить его.

Открытая ссылка не заменяет прочитанного источника. Созданный файл не доказывает его качество. Сохранение в кабинете не подтверждает видимость получателю. Для внешних действий нужны соответствующие полномочия, а для вывода «готово» — свидетельства.

Задачу и решения удобно хранить обычным текстом. Таблица может оставаться в XLSX, презентация — в PPTX, документ — в DOCX. Проверяем тот формат, которым будет пользоваться человек.

## Для тех, кто работает с файлами

Этот раздел можно пропустить. Агент сохраняет учебные работы в папке `student-workspace/`. Файл `.md` — обычный текст с простой разметкой заголовков и списков, которую называют Markdown. Это не программа и не команда.

Папка учебных работ исключена из истории изменений Git. Это помогает не опубликовать ее случайно вместе с курсом, но не запрещает подключенному ИИ читать файлы.

```text
START_HERE.md       # инструкция агенту-наставнику
course/             # методика, 12 модулей, маршруты, материалы ведущего
templates/          # рабочие шаблоны
examples/           # запросы, законченные кейсы и учебные данные
exercises/          # задания
research/           # исследование и границы актуальности
scripts/            # необязательные проверки для автора и агента
student-workspace/  # личные учебные проекты, исключены из Git
```

Если уже пользуешься Git, курс можно скачать так:

```bash
git clone https://github.com/tduhfajd/Training-course-on-ai-agents.git
cd Training-course-on-ai-agents
```

Для обычного чата эти команды не нужны.
