# Чек-лист завершения первого проекта

Проект считается завершенным, если:

- [ ] создана папка проекта внутри `student-workspace/`;
- [ ] есть `idea.md` или `task.md`;
- [ ] задача описана понятным языком;
- [ ] агент пересказал задачу, и ученик подтвердил понимание;
- [ ] зафиксировано, что решает человек и что помогает делать агент;
- [ ] есть 2-3 варианта решения;
- [ ] выбран один подход;
- [ ] решение записано в `decisions.md`;
- [ ] создан первый полезный результат в `results/`;
- [ ] результат проверен;
- [ ] внесены точечные улучшения;
- [ ] создан `learning-summary.md`;
- [ ] ученик может объяснить, как повторить этот процесс в другой задаче.
