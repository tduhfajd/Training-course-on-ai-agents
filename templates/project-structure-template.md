# Рекомендуемая структура проекта

```text
project-name/
  idea.md или task.md
  README.md
  materials/
  knowledge-base/
  notes/
  results/
  exports/
  skills/
  decisions.md
```

## Назначение папок

`materials/` - исходные файлы, ссылки, документы, изображения, таблицы.

`knowledge-base/` - структурированные знания, которые собрал агент или человек.

`notes/` - рабочие заметки, промежуточные мысли, черновики.

`results/` - финальные или почти финальные результаты.

`exports/` - производные файлы для внешней передачи: PDF, DOCX, PPTX, HTML.

`skills/` - черновики или проектируемые скилы, если из задачи появился повторяемый процесс.

`decisions.md` - важные решения и причины, почему они были приняты.
