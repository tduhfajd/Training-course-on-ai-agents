# Где сохранить проект

Для первого раза достаточно **одного документа** с разделами «Задача», «Результат», «Проверка», «Что запомнить». В обычном чате скопируй итог в привычные заметки.

Если агент работает с папкой курса, он может сам сохранить документ:

```text
student-workspace/my-project/
  task.md
```

Здесь `student-workspace` — папка учебных работ, `my-project` — пример имени твоей задачи, `task.md` — текстовый файл. Не нужно самостоятельно вводить этот пример как команду.

## Когда понадобится несколько файлов

Для большой или длительной задачи можно разделить материалы:

- materials/ — исходные файлы;
- results/ — результаты;
- decisions.md — важные решения;
- verification.md — проверка;
- learning-summary.md — итог обучения;
- handoff.md — запись для продолжения в другом чате.

Эти имена — удобное соглашение, а не обязательные требования. Агент может организовать файлы сам. Не создавай пустые папки ради структуры.
