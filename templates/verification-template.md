# Проверка результата

Это подробный вариант для сложной задачи. Для первого проекта достаточно раздела «Проверка» в общем документе: что сверили, что получилось и что осталось неизвестным.

Дата:
Проверяемый файл / объект / версия:
Задача и критерии:

| Критерий | Способ проверки | Наблюдаемое свидетельство | Статус |
| --- | --- | --- | --- |
| | | | |

Статусы: пройдено / не пройдено / не проверено.
Свидетельство — конкретная строка, расчет, просмотр, результат сценария или повторное чтение объекта, а не общая фраза «проверено агентом».

## Личная проверка ученика

## Дефекты и повторная проверка

Что исправлено? Какие критерии проверены после изменения?

## Границы

Что не проверялось? К каким объектам и условиям относится вывод?

## Решение

Готово в заявленном объеме / нужны исправления / не хватает данных.
Кто принял результат? Не подставлять согласие человека автоматически.
